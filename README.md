# YT Web Player (Client YouTube Alternatif & Sans Pub)

Client web alternatif pour YouTube hébergé directement sur **GitHub Pages**, conçu pour permettre l'accès aux vidéos même sur les réseaux filtrés (travail, université) où `youtube.com` est bloqué.

---

## 📺 Accès direct

- **Lien GitHub Pages** : `https://mohamedguell.github.io/yt/`

---

## ⚡ Fonctionnalités

- **4 Moteurs de lecture au choix** :
  1. **YouTube NoCookie** : Utilise le domaine officiel `youtube-nocookie.com` souvent autorisé sur les réseaux professionnels pour les formations et intranets.
  2. **Invidious (yewtu.be)** : Moteur open-source indépendant sans publicité ni traqueurs Google.
  3. **Invidious (nadeko.net)** : Instance de secours alternative.
  4. **Piped (piped.video)** : Moteur léger passant par des relais de streaming chiffrés.
- **Recherche intégrée** : Tapez n'importe quel mot-clé pour trouver des vidéos.
- **Support des liens directs** : Collez n'importe quel lien YouTube (`youtube.com/watch?v=...`, `youtu.be/...`, ou shorts) pour lancer la lecture instantanément.
- **Interface sombre moderne et responsive** (compatible mobile, tablette et PC).
